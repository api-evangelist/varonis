Key takeaways Least privilege for AI agents gives each agent its own identity and only the access a specific task needs, for only as long as that task runs. Human-centric access models break down for agents, which inherit user permissions, run on shared service accounts, and act at machine speed. OWASP names excessive permissions as a root cause of excessive agency.
